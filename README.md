# Excel Logical Functions Practice Project

## Project Overview
This project demonstrates practical usage of Excel logical functions using the Superstore Sales Dataset. The workbook focuses on applying business-oriented scenarios commonly used in data analysis, reporting, and KPI evaluation workflows.

---

## Skills Practiced
- IF Function
- IFS Function
- AND Function
- OR Function
- IFERROR Function
- Business Rule Classification
- Error Handling
- KPI Logic
- Sales & Profit Analysis

---

## Dataset Used
- Superstore Sales Dataset

---

## Functions & Business Scenarios Covered

### IF Function
- Profit vs Loss Classification
- Sales Category Detection
- Discount Alert System
- Shipping Status Classification

### IFS Function
- Sales Performance Classification
- Profit Rating Segmentation
- Discount Risk Categorization

### OR Function
- Order Review Alert
- Shipping Attention Needed
- Priority Attention Detection

### AND Function
- High Performance Orders
- Successful Discount Analysis
- Bulk High-Value Orders

### IFERROR Function
- Product Lookup Error Handling
- Sales per Quantity Calculation
- Profit Margin Calculation
